# 获客虾（独立端）

获客虾只包含抖音主页/视频评论采集、线索筛选与 CSV 导出；不包含直播复盘、直播监听、短视频 AI 工作台等页面。

## 本地启动

双击 [启动获客虾.bat](启动获客虾.bat)，浏览器会打开 `http://127.0.0.1:8922`。

数据单独保存在：

```text
%LOCALAPPDATA%\LeadShrimp\data
```

这里保存抖音可信 Cookie、采集的线索、导出文件和本机授权缓存；它不会读取或写入复盘虾的数据目录。

## 授权边界

- 固定产品码：`lead_shrimp`
- 权益：`lead_radar`、`export`
- 卡密激活请求带固定产品码，服务器拒绝其他产品的卡密。
- 服务器签发 Ed25519 授权包；本机缓存使用 Windows DPAPI（不可用时使用设备派生 AES-GCM）保护。
- 正式商业构建必须把 `pipeline/license_runtime.py` 替换为固定的强制授权配置；私钥、管理员令牌、卡密库绝不能放入安装包。

## 发布前置条件

需要先在 `license.runmo.art` 的授权服务部署包含 `lead_shrimp` 的服务端代码，再用管理员令牌通过 `/admin` 生成卡密。仅把 EXE 上传到 OSS 不会替代这一步。
